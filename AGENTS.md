# themebuilder - for Muse / Codex / ChatGPT / OpenCode agents
Flow: `themebuilder spec <reference URL or mirror dir> -o spec.json`, then write theme.json (facts + own assets with provenance), `themebuilder map spec.json --theme theme.json -o map.json`, `themebuilder scaffold map.json --spec spec.json -o <project>`, `themebuilder compare spec.json <project>`. Self-learning: every spec/scaffold/compare updates its knowledge file (see `themebuilder evolve`). Spec is values only - never copy reference code or copy text into a build. Never call it done until compare diff_count is 0 AND a visual scroll-stop probe (desktop + 390px) passes.
