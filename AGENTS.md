# themebuilder - for Muse / Codex / ChatGPT / OpenCode agents
RULE: whichever reference website is given, the finished build must match its UI 100% exactly - layout, sections and their order/formation, fonts, colours, spacing, transitions, animations and scrolling. Only the theme content changes. No simplification, no interpretation, no "close enough." A build is not done until `compare` shows 0 diffs AND the visual scroll-stop probe (desktop + 390px) matches the reference side by side.
Two sides, kept separate: REFERENCE -> `themebuilder spec <reference URL or mirror dir> -o spec.json`. THEME -> `themebuilder collect` with ANY of --site / --maps / --business / --instagram (+ --instagram-dir for photos collected via a connected Instagram account) -o themes/<theme name>: it gathers the theme business's own facts + photos (provenance on every photo) into theme.json + collected.json (gaps named, never invented). Then `themebuilder map spec.json --theme theme.json -o map.json`, `themebuilder scaffold map.json --spec spec.json -o <project>`, `themebuilder compare spec.json <project>`. Self-learning: every spec/scaffold/compare updates its knowledge file (see `themebuilder evolve`). Spec is values only - never copy reference code or copy text into a build. Never call it done until compare diff_count is 0 AND a visual scroll-stop probe (desktop + 390px) passes.
